SOMA modifier

/modifier - by p-e-w and contributors - planned

A planned multi-directional modifier intended to sit alongside ARA as a shipped plugin.

What it does

The maintainer described SOMA as a multi-directional transport technique that uses a fixed number of linear paths. It is not released in the current master branch; the plugin interface was reworked specifically so techniques like SOMA can be added. List it here to track intent, not to install today.

Where to find it

  • Plugin system PR
  • Modifier interface

How to use it

  1. Check the current Heretic release notes before attempting anything; this is not shipped yet.
  2. If a SOMA plugin appears, register it in the modifiers list in place of ARA.
  3. Keep your quality scorer active and compare trials against ARA on the same model.
  4. Do not copy ARA settings into SOMA without checking the new parameter schema.

Config fragment

# Not released yet. When available, it will replace the ARA entry:
modifiers = [
    { plugin = "heretic.modifiers.soma.SOMA" },
]
