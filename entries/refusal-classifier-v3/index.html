Refusal Classifier V3

/model - by VINAY-UMRETHE - available

A family of refusal classifiers for BERTClassifier, published in small and large variants.

What it does

Successor models to the V1 and V2 refusal classifiers commonly used with Heretic's BERTClassifier scorer. The author reports a new non-compliant label and stress-test results for both sizes. The large variant is the more accurate of the two according to the author's published tests; treat those numbers as author-reported, not independent benchmarks.

Where to find it

  • V3 Small
  • V3 Large
  • V2 model

How to use it

  1. Enable BERTClassifier in the scorers list with optimization = minimize.
  2. Choose V3-Large for accuracy or V3-Small for lower memory use.
  3. Set model to the full Hugging Face repository ID and match_labels to the labels named in that model's card.
  4. Run a small sample and compare verdicts against your previous classifier before switching fully.

Config fragment

scorers = [
    { plugin = "heretic.scorers.bert_classifier.BERTClassifier", optimization = "minimize" },
]

[scorer.BERTClassifier]
model = "VINAY-UMRETHE/Refusal-Classifier-V3-Large"
match_labels = ["full_refusal", "partial_refusal", "non_compliant"]
max_length = 512

Setup prompt

Switch my local Heretic BERTClassifier scorer to VINAY-UMRETHE/Refusal-Classifier-V3-Large. Enable the BERTClassifier scorer with optimization = minimize if it is not already in the scorers list, and set model = "VINAY-UMRETHE/Refusal-Classifier-V3-Large" under [scorer.BERTClassifier]. Read the model's Hugging Face card and use its exact label names for match_labels; do not guess labels from memory. Keep max_length = 512 and leave KLDivergence minimizing if it is present. Verify by starting a short Heretic run and confirming the model ID appears in the loaded-classifier log line, then compare the first trial's refusal verdicts with my previous classifier.
