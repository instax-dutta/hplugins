Krea2Good

/scorer - by zubzer0 - community

Minimizes the p90 drift of good image prompts so an ablation leaves benign Krea 2 conditioning stable.

What it does

The first half of a paired scorer for image-generating VLMs. It takes the largest conditioning drift left after discarding the ten percent of prompts that moved most, then asks the optimizer to minimize it. Lower values mean the good prompts kept their original trajectory. Use it together with Krea2Bad and a KL divergence scorer.

Where to find it

  • Discord post with config
  • Local plugin source

How to use it

  1. Copy plugins/krea2_drift_v2.py into the directory you run Heretic from.
  2. Add the Krea2Good and Krea2Bad entries to scorers, with Krea2Good set to minimize.
  3. Point [scorer.Krea2Good.prompts] at a file of good image prompts and keep a KL divergence scorer in the list.
  4. Compare the reported 'Krea2 good p90max' across trials; it should stay low while Krea2Bad rises.

Config fragment

{ plugin = "./krea2_drift_v2.py:Krea2Good", optimization = "minimize" },

[scorer.Krea2Good]
checkpoint_path = "Krea2_turbo_bf16.safetensors"
max_length = 512
noise_limit = 0.01

[scorer.Krea2Good.prompts]
dataset = "GOOD_prompts.txt"
split = "[:200]"

Setup prompt

Install the Krea2Good scorer in my Heretic working directory. Copy plugins/krea2_drift_v2.py into your Heretic working directory as krea2_drift_v2.py. Add { plugin = "./krea2_drift_v2.py:Krea2Good", optimization = "minimize" } to the scorers list, keep a KLDivergence entry set to minimize, and add the matching Krea2Bad entry set to maximize. In [scorer.Krea2Good] set checkpoint_path to my local Krea 2 Turbo safetensors file, max_length = 512, measure_noise_floor = true, noise_limit = 0.01. In [scorer.Krea2Good.prompts] set dataset to a local good-image-prompt text file and split = "[:200]". This scorer measures conditioning drift, so use a Qwen3-VL model and keep the KL score low to avoid breaking the model. Verify with a short trial run and confirm a 'Krea2 good p90max' line in the output. Do not edit other scorers or the plugin code.
