MPOA abliteration

/modifier - by p-e-w and contributors - available

Magnitude-preserving orthogonal ablation, available through Heretic's directional abliteration modifier.

What it does

A modifier technique that preserves norm and uses orthogonal directions during abliteration. It began as a community pull request and is now supported by the shipped Abliteration modifier through settings such as row normalization and orthogonalize-direction. Community reports suggest it helps many models, but the maintainer notes that Heretic's parameter search plus MPOA beats the original MPOA parameter strategy.

Where to find it

  • Original PR discussion
  • Abliteration source

How to use it

  1. Switch the modifiers list to heretic.modifiers.abliteration.Abliteration.
  2. Enable the MPOA-related flags under [modifier.Abliteration] in config.toml.
  3. Keep a quality scorer such as KL divergence or a benchmark active so parameter search has a signal.
  4. Compare against ARA on the same model before choosing.

Config fragment

modifiers = [
    { plugin = "heretic.modifiers.abliteration.Abliteration" },
]

# MPOA-related flags from the PR discussion:
# --winsorization-quantile=0.995 --row-normalization=full --orthogonalize-direction
