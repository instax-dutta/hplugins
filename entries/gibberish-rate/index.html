GibberishRate

/scorer - by randomlygeneratedusername - proof-of-concept

Flags trials whose responses turn into gibberish by counting distinct Unicode scripts.

What it does

A community scorer written with coding-model assistance after ARA runs produced incoherent outputs. It probes a few prompts per trial and classifies a response as gibberish when it contains more than a configured number of distinct scripts. By default it skips or aborts affected trials rather than adding another optimization objective. No source repository was published; only the config snippet is available.

Where to find it

  • Discord config snippet
  • Heretic plugin interface

How to use it

  1. Find or write a GibberishRate plugin class that reads n_prompts, max_scripts, and min_characters_per_script from its config section.
  2. Save it as gibberish_rate.py next to config.toml.
  3. Add the [scorer.GibberishRate] block from the source snippet, with optimization = none if you only want bad trials skipped.
  4. Run a short ARA trial set and confirm the probe responses are checked.

Config fragment

[scorer.GibberishRate]
n_prompts = 5
max_scripts = 3
min_characters_per_script = 1
print_responses = false

[scorer.GibberishRate.prompts]
dataset = "mlabonne/harmless_alpaca"
split = "test[:100]"
column = "text"
