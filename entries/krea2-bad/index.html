Krea2Bad

/scorer - by zubzer0 - community

Maximizes the p90 drift of bad image prompts so abliteration visibly changes how the model handles them.

What it does

The second half of the paired Krea 2 scorer. It keeps the smallest conditioning drift after discarding the ten percent of prompts that moved least, then maximizes it. The author's sign of success is Krea2Bad p90min rising above Krea2Good p90max. It correlates with refusal rate on image prompts, so it is useful only alongside a quality scorer such as KL divergence.

Where to find it

  • Discord post with config
  • Local plugin source

How to use it

  1. Copy plugins/krea2_drift_v2.py into your Heretic working directory as krea2_drift_v2.py and pair this scorer with Krea2Good.
  2. Point [scorer.Krea2Bad.prompts] at a file of bad or restricted image prompts.
  3. Set optimization = maximize and keep KLDivergence minimizing.
  4. Look for Krea2 bad p90min above Krea2 good p90max as the intended result.

Config fragment

{ plugin = "./krea2_drift_v2.py:Krea2Bad", optimization = "maximize" },

[scorer.Krea2Bad]
checkpoint_path = "Krea2_turbo_bf16.safetensors"
max_length = 512
noise_limit = 0.01

[scorer.Krea2Bad.prompts]
dataset = "BAD_prompts.txt"
split = "[:200]"

Setup prompt

Install the Krea2Bad scorer in my Heretic working directory. Copy plugins/krea2_drift_v2.py into your Heretic working directory as krea2_drift_v2.py and add { plugin = "./krea2_drift_v2.py:Krea2Bad", optimization = "maximize" } to the scorers list. Pair it with { plugin = "./krea2_drift_v2.py:Krea2Good", optimization = "minimize" } and with KLDivergence set to minimize. In [scorer.Krea2Bad] set checkpoint_path to my local Krea 2 Turbo safetensors file, max_length = 512, and noise_limit = 0.01. In [scorer.Krea2Bad.prompts] use a local file of restricted image prompts and split = "[:200]". The plugin is prompt-sensitive, so keep the KL score low and watch for a broken model. Verify by running a short trial and checking that a 'Krea2 bad p90min' line is printed and that it can exceed the good score. Do not modify other scorers.
