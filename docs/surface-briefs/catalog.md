# Surface brief: catalog (desktop-first web, read mode)

Audience: Heretic users looking for a non-default scorer, modifier, config, or companion model, usually with a specific failure in mind. Job: find something that fits, understand it in one sentence, get the source, and leave with a setup prompt. Action: select an entry and copy its prompt. Proof: real entry text from `HERETIC_PLUGINS.md`; no invented screenshots or benchmarks. Constraints: GitHub Pages, no server, no dependencies, sub-100 KB of code and data.

Chosen direction: **exploded parts manifest**, seed `28f5ae27`, candidate 7 of the grounded list, dice-assigned.

## Direction contract

THESIS: A plugin registry as an exploded service plate, not a card gallery. The list is a numbered parts index with leader lines into a persistent dossier; the setup prompt is the part that gets lifted out and carried away.

OWN-WORLD: Cool grey paper and ink, hairline rules, registration crosses, tabular mono numerics, a sticky index spine, and one cobalt accent reserved for the active selection. Status is a stamped mark plus text, never color alone.

STORY: The visitor sees a finite, numbered inventory. Filtering narrows the plate; selecting a row rethreads the callout into the dossier, where source links and the manifest strip answer "where do I get it" and "how do I install it".

FIRST VIEWPORT: A fixed left spine holds the wordmark, entry count, and type counts. To its right, immediately visible, a single sign-band holds search and type filters. Below it, numbered entries begin above the fold. On desktop a right dossier panel is present from the first frame with the selected entry's manifest strip and its copy action. No marketing hero.

FORM: Exploded-view technical plate (candidate 7). The "manifest strip" is the signature interaction: a line-numbered monospace prompt block whose copy action gives visible confirmation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Challenger verdicts

- Silk drawcord cape: declined. Donation: named states as physical marks, so status gets a stamp glyph plus text.
- Mesophotic deep dive: declined. Donation: one vertical axis ruling every line, so the index spine is persistent and structural.
- Film cutting bench: competitive. Donation: state is a mark, not a hue; reinforced the status stamps.
- Ikeda datamatics: declined. Donation: tabular mono numerics in tight columns for the index numbers.
- Airport wayfinding: competitive. Donation: one message per sign band with controls locked to the edge; applied to the filter bar.
- Civic prospectus: declined. Donation: spend all color in one place; cobalt appears only on active selection and links.
