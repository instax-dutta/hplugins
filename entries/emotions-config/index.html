Emotion steering config

/config - by p-e-w - available

An official non-default config that steers emotions by minimizing negative and maximizing positive labels.

What it does

Uses two instances of BERTClassifier with a DistilRoBERTa emotion model, plus KL divergence. One instance minimizes negative emotions and another maximizes positive ones, giving a concrete example of how multiple instances of the same scorer can co-optimize opposite directions. It ships in the repository but is not the default.

Where to find it

  • Config file
  • Default config reference

How to use it

  1. Copy config.emotions.toml to config.toml in your Heretic working directory.
  2. Edit the two emotion label sets to match the classes of the classifier model you use.
  3. Choose prompts that naturally evoke the emotion you want to change.
  4. Run a short trial set and inspect responses before committing to a long run.

Config fragment

scorers = [
    { plugin = "heretic.scorers.kl_divergence.KLDivergence", optimization = "minimize" },
    { plugin = "heretic.scorers.bert_classifier.BERTClassifier", optimization = "minimize", instance_name = "negative_emotions" },
    { plugin = "heretic.scorers.bert_classifier.BERTClassifier", optimization = "maximize", instance_name = "positive_emotions" },
]

Setup prompt

Install the official emotion-steering configuration in my local Heretic working directory. Copy config.emotions.toml to config.toml, but first back up my current config. Confirm the three scorer entries are present: KLDivergence minimizing, BERTClassifier instance negative_emotions minimizing, and BERTClassifier instance positive_emotions maximizing, each with its own [scorer.BERTClassifier_<instance_name>] section. Check that the label lists match the classifier model named in the config, and edit them if my chosen model has different labels. Choose prompts that evoke the target emotion. Verify by starting a short run and confirming all three scorers load with their instance names printed.
