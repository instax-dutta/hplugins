vantablack refusal classifier

/model - by saidutta69 - available

A refusal classification model for the BERTClassifier scorer, with separate full and partial refusal labels.

What it does

A text-classification model published for Heretic's BERTClassifier scorer. It uses two refusal labels and text pairs, so it can distinguish a full refusal from a partial one. Community reports found it more conservative than keyword matching on image-generation prompts, which may suit different workflows.

Where to find it

  • Model on Hugging Face
  • BERTClassifier docs

How to use it

  1. Enable BERTClassifier by adding it to the scorers list; it is not enabled by default.
  2. Set model to saidutta69/vantablack and match_labels to the two refusal labels.
  3. Enable use_text_pairs so prompts and responses are classified together.
  4. Compare its refusal count with KeywordRate before a long run.

Config fragment

scorers = [
    { plugin = "heretic.scorers.bert_classifier.BERTClassifier", optimization = "minimize" },
    { plugin = "heretic.scorers.kl_divergence.KLDivergence", optimization = "minimize" },
]

[scorer.BERTClassifier]
model = "saidutta69/vantablack"
match_labels = ["full_refusal", "partial_refusal"]
use_text_pairs = true
max_length = 512

Setup prompt

Configure the saidutta69/vantablack refusal classifier with Heretic's BERTClassifier scorer in my local config.toml. Add { plugin = "heretic.scorers.bert_classifier.BERTClassifier", optimization = "minimize" } to the scorers list, keep KLDivergence minimizing, and add a [scorer.BERTClassifier] section with model = "saidutta69/vantablack", match_labels = ["full_refusal", "partial_refusal"], use_text_pairs = true, and max_length = 512. BERTClassifier is not enabled by default, so make sure the entry is present rather than only the settings section. Verify by starting Heretic and checking the log line that reports which classifier model was loaded, then compare the first trial's refusal count with KeywordRate.
