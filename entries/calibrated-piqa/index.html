Calibrated PIQA

/scorer - by electroglyph - community

A Heretic fork with a benchmark scorer tuned to PIQA questions that flip between right and wrong.

What it does

Built on the mainline BenchmarkScore idea, this fork repeatedly evaluates a model, keeps questions whose answers flip-flop, and batches those questions to get a higher-signal quality metric. It was used while comparing ablated models against GPQA results. The author reports a modest improvement in signal over plain PIQA, not a perfect correlation.

Where to find it

  • Fork with the scorer
  • Benchmark results model

How to use it

  1. Clone the fork instead of mainline Heretic if you want the author's exact scorer.
  2. Configure a BenchmarkScore-style entry with optimization = maximize and select the calibrated task the fork defines.
  3. Compare its score against KL divergence on the same trials before trusting it.
  4. Use a short benchmark so it stays fast enough for trial-level scoring.

Config fragment

scorers = [
    { plugin = "heretic.scorers.keyword_rate.KeywordRate", optimization = "minimize" },
    { plugin = "heretic.scorers.benchmark_score.BenchmarkScore", optimization = "maximize" },
]

[scorer.BenchmarkScore]
task = "piqa"
metric = "acc_norm,none"
