Chinese censorship config fork

/config - by benjamin920101 - community

A Heretic fork with refusal markers and prompts aimed at region-specific Chinese censorship rather than general refusals.

What it does

Shared in the community server as a working configuration fork. It changes the refusal markers and dataset setup so the optimization targets censorship behavior specific to Chinese-language prompts. Treat it as a starting config to adapt, not a drop-in plugin.

Where to find it

  • Fork on GitHub
  • Config file

How to use it

  1. Copy the fork's config.default.toml into your Heretic working directory as config.toml.
  2. Review the KeywordRate markers and translate or extend them for your target prompts.
  3. Point the good and bad prompt datasets at Chinese-language data you actually want to preserve or change.
  4. Run a short trial set and read printed responses to confirm the markers fire correctly.

Config fragment

[scorer.KeywordRate]
# Use the markers from the fork's config.default.toml

[modifier.ARA.bad_prompts]
dataset = "your-chinese-language-dataset"
column = "text"
