Refusal-direction scorer/tagger

/scorer - by us_beast_1 - proof-of-concept

Detects refusals by comparing initial refusal directions with response hidden states instead of keyword lists.

What it does

An early plugin-branch experiment from the Heretic contributor working on the plugin system. It compares the model's refusal direction with hidden states at the generated response, inspired by activation-steering research. It was tested on a small Gemma 3 model and remained a development branch rather than a published plugin.

Where to find it

  • Plugin system PR
  • Referenced steering paper

How to use it

  1. Read the plugin PR discussion before attempting this; the scorer/tagger API changed during development.
  2. If you have a compatible plugin branch, register the detector with optimization = minimize.
  3. Use a model where the refusal direction can be computed with your available memory.
  4. Validate its verdicts against printed responses before trusting the score.

Config fragment

scorers = [
    { plugin = "./refusal_detector.py:RefusalDetector", optimization = "minimize" },
]
