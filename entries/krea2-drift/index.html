Krea2Drift

/scorer - by zubzer0 - community

Measures how far an ablation shifts the text conditioning that Krea 2 feeds to its image model, without generating an image.

What it does

Reads the fused text tensor from twelve tapped Qwen3-VL layers and reports the mean token cosine drift against the unmodified model, in percent. It is a diagnostic: the shared config uses optimization = none so the score is visible without steering the optimizer. Very sensitive to prompt choice, and it needs a Krea 2 Turbo safetensors checkpoint and roughly 16 GB of VRAM.

Where to find it

  • Discord post with config
  • Extracted inventory

How to use it

  1. Copy plugins/krea2_drift.py into the working directory you run Heretic from.
  2. Copy the [scorer.Krea2Drift] block from the source post into config.toml and set checkpoint_path to your local Krea 2 Turbo safetensors file.
  3. Keep optimization = none if you only want the number printed per trial.
  4. Run Heretic on Qwen3-VL-4B-Instruct and read the Krea 2 drift line in the trial output.

Config fragment

scorers = [
    { plugin = "./krea2_drift.py:Krea2Drift", optimization = "none" },
]

[scorer.Krea2Drift]
checkpoint_path = "krea2turbo-bf16.safetensors"
max_length = 512
noise_limit = 0.01

[scorer.Krea2Drift.prompts]
dataset = "good_image_prompts.txt"

Setup prompt

Set up the Krea2Drift diagnostic scorer in my local Heretic installation. Copy plugins/krea2_drift.py into your Heretic working directory as krea2_drift.py. Add an entry { plugin = "./krea2_drift.py:Krea2Drift", optimization = "none" } to the scorers list in config.toml, then add [scorer.Krea2Drift] with checkpoint_path pointing at my local Krea 2 Turbo safetensors file, max_length = 512, noise_limit = 0.01, and a [scorer.Krea2Drift.prompts] section whose dataset is a local text file of image prompts. Keep optimization as none: this scorer is a measurement, not an objective. Use a Qwen3-VL model and tell me if my VRAM is below roughly 16 GB before running. Verify by starting a one-trial Heretic run and confirming a 'Krea 2 drift' line appears in the trial output. Do not generate an image and do not change any other scorer.
